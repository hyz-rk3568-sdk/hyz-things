### Front

小P S1｜直言命题：所有、有的如何推？何时画图、何时用三段论？

### Back

**集合范围**
- 所有 A 都是 B：A 包含于 B，可以全同；逆否是「所有非 B 都是非 A」。
- 有的 A 是 B：交集可以到 100%，不能擅自推「有的 A 不是 B」；可交换为「有的 B 是 A」。
- 有的 A 不是 B：不能换成「有的 B 不是 A」。
- 所有 A 都不是 B：两个集合无交集。
- 「所有 A 都是 B」的矛盾是「有的 A 不是 B」；「有的 A 是 B」的矛盾是「所有 A 都不是 B」。

**三段论：找「所有……都是……」当桥**
1. 所有 A 是 B + 所有 B 是 C ⇒ 所有 A 是 C。
2. 有的 A 是 B + 所有 B 是 C ⇒ 有的 A 是 C。
3. 有的 A 是 C + 所有 A 是 B ⇒ 有的 B 是 C。
4. 有的 A 不是 C + 所有 A 是 B ⇒ 有的 B 不是 C。

**小P做题顺序**：2 句优先三段论；3～4 句优先画图，**先实线后虚线**；条件更多可回三段论找桥。「有的」不能当「所有」，两个「有的」通常传不出确定结论。
