## 1. 目标与用户确认的产品规则

以现有 **question-bank practice（真题答题页）** 为标准，将资料分析综合训练、逻辑判断、数量关系的答题/交卷后复盘，尽量统一为同一套共享 UI/交互组件。

必须统一：顶部「今日刷题 / 今日时长」两条进度条的高度、宽度、字体及间距；左右双屏比例可拖动并记忆；答题卡；题号/上一题/下一题导航；选项作答/判分样式；滚动、触控翻题、Apple Pencil 草稿、沉浸式布局、桌面及移动端响应式行为。保留各题型特殊数据和操作，不以复制页面或复制 CSS 实现“看上去相似”。

**功能权限按题目来源而非页面菜单决定：**

| 题目来源 | 收藏 | 创建 Flashcard | 入错题库 / 错题复练 | 普通作答、交卷和解析 | 答题卡、计时、会话历史、重做 |
| --- | --- | --- | --- | --- | --- |
| 真题 Question Bank（整卷、原卷模块、跨卷模块） | 保留 | 保留 | 保留 | 保留 | 保留 |
| 已入库的题库专项合集、真题专项复练 | 保留 | 保留 | 保留 | 保留 | 保留 |
| AI 生成题（包括资料分析综合、形式/逻辑、数量的 AI 题） | **不提供** | **不提供** | **不写入、不参与错题复练** | 保留 | 保留 |

术语消歧：「专项训练」是导航入口，不代表其中每道题都是真题。**位于“专项训练”菜单中的 AI 生成题仍遵守 AI 行规则**；只有可追溯、稳定身份的真题/已入库专项题才具备收藏、创建 Flashcard 和入错题库资格。不能只判断 TrainingMode 或页面标题。

AI 题仍可保存本轮答案、正确/错误状态、成绩、练习历史并回放原题；这些记录**不等于**把单道题加入错题资产。继续按现有规则累计学习计时和普通刷题统计，避免因为禁用错题而误伤计时、作答或生成题的原有调度/卡片方法关联。AI 题已有“查看关联方法卡”可以作为阅读入口保留，但绝不借此自动创建新 Flashcard。现存历史不自动删除：若存在不合规的错题/收藏记录，先审计来源和迁移/清理风险，再在实施 PR 明确处理。

## 3. UI 统一的设计方案

### 3.1 顶部进度条与状态栏

- 只保留一套 StudyGoalBars 实现，定义统一的轨道高度、占位宽度、标签/数值字号、字重、行高、两条轨道间距。
- 在 question-bank practice、comprehensive、logic、quantitative 的**实际作答页和复盘页**采用相同视觉尺寸；对比两张截图中的今日刷题/今日时长区域。
- 统一目标进度显示与分母、计时更新和点击进入学习统计的行为，不另起一套计时器。
- 顶栏外围容器使用一致的 flex 收缩、断点和最小宽度约束，避免一个页面压窄进度条，另一个页面撑满。
- 窄屏允许按统一策略换行/简写，但不能截断数值、遮挡计时器与导航；以实际计算后的 CSS 尺寸验收，而非仅比较 class 字符串。
- Codex 限额只属于已支持它的真题 AI 解析相关页面；AI **出题训练页面**不显示限额，不触发无意义的额度请求。

### 3.2 共享双屏工作区

- 以 TrainingSplitWorkspace 为单一可拖动实现，让资料分析、逻辑、数量的作答和复盘都使用相同的分隔柄。
- 保留默认 60:40、最小宽度/高度、触摸长按、键盘方向键微调和 Home 恢复默认；重新检验横/竖屏的断点、布局和尺寸限制。
- 用户更改比例后，各支持页面读取统一偏好；已有 question-bank-split 的存储值应兼容迁移或继续读取，不能令已有用户设置突然失效。区分横屏/竖屏偏好，避免跨方向套错。
- 分栏语义对材料/题目、题目/选项、题目/解析分别可配置，正确设置分隔柄 aria-label；共用组件不应硬编码“题目与解析”。
- 拖动时不丢失两栏现有 scrollTop、草稿/手写坐标；不得与触控翻题、选项点击、滚动手势争抢事件。切题时按既有各科需求决定是否重置滚动，不强制套一条规则。
- 保留资料分析「材料左栏 + 题目/选项右栏」与逻辑/数量「题目左栏 + 选项/解析右栏」的内容差异；统一的是容器、滚动/拖动/工具交互，不是把材料题错误改成独立题。

### 3.3 答题卡、导航及内容

- 抽取/复用 question-bank practice 的答题卡展示、题目状态（未答、已答、复盘正确/错误）、打开关闭与滚动位置记忆；每种模式通过 props 提供题号、题组、状态、跳转回调。
- 资料分析保持材料 1–4、每份 5 题、当前材料题号和跳转；逻辑/数量按各自题数；真题保留原卷题号、共享材料映射、题库合集分组。
- 上一题/下一题、题目滑动切换、交卷前后颜色与不可提前暴露正确答案的规则保持一致。未交卷状态只能显示“已作答”，不能提前显示对错。
- 统一题干、选项、解析的默认字号/行高、选中态、正确/错误态、内容 padding、图像/Markdown/KaTeX 与滚动按钮；不得破坏题干中图片、公式、表格或选项超长换行。
- Apple Pencil 草稿、工具条开关、画笔撤销/重做/清屏及禁用滚动保护沿用现有共享逻辑；与拖动手柄和答题卡浮层同时使用要稳定。
- 作答中/复盘中各自的动作区按能力开关显隐：保留已有返回、暂停/计时、查看练习记录、原题重做、收藏/Flashcard 等**有资格的**操作；不盲目把真题 AI 解析、Codex 限额、真题操作菜单整体搬进 AI 题页面。

### 3.4 功能资格的单一判断来源

建议在现有题目视图/操作模型与服务端入库边界明确可验证的来源资格，例如：
- 可追溯的 Question Bank 题目/专项合集：允许收藏、错题库、创建 Flashcard。
- AI 生成会话题：禁止以上三类资产操作。

具体字段和权限接口以当前后端模型为准，**先复用已有身份来源，不为 UI 新建第二套来源真相**。

必须同时约束：
1. UI：不显示 AI 题收藏、创建 Flashcard、错题收藏/错题复练入口。
2. API/应用层：即使手工调用接口，也不得将 AI 题写成真题的错题、收藏或 Flashcard；校验与题目稳定身份、授权/CSRF 匹配。
3. 数据：真题独立 question-bank.db 状态不受影响；AI 题保留既有答题会话、成绩与普通历史记录，不通过共享 UI 意外写入真题资产表或 Flashcard 数据库。
4. 已有 AI 题调度的 card-performance / 相关方法卡展示与真实“错题库”分别核查；本计划不擅自清除调度指标或历史数据。

## 4. 分阶段实施（后续功能 PR 执行，不在本 PR 写代码）

### P0：基线与测试先行
- 固定真题、题库专项、AI 资料分析、AI 逻辑、AI 数量 5 类场景的组件映射、数据来源、交卷/复盘/历史路径。

- 核实后端是否已对 AI 题写入错题资产；若没有，只补明确回归保护，不做无效数据库重构。

### P1：共享视觉与布局
- 收敛 StudyGoalBars 样式和各模式顶部调用容器。
- 让综合/逻辑/数量复用 resizable TrainingSplitWorkspace；兼容老比例偏好与断点行为。
- 统一题目、选项、解析的共性样式；保留资料分析/逻辑/数量各自滚动与题型专属展示。

### P2：答题卡与行为收敛
- 复用/提取答题卡壳、题号按钮与状态色，并用可配置的数据映射接入各模式。
- 统一导航、触摸翻题与动画、材料切换、草稿工具条的事件互斥和可访问性。
- 每个页面只保留自己的题目数据、计时期限、答题保存/交卷/历史和特殊按钮控制。

### P3：题目来源权限收敛
- 复用或增加单一来源资格判定；只有真题/入库专项题具备错题、收藏、创建 Flashcard。
- AI 题页面不显示相关按钮，不触发写入；服务端与存储边界同样阻止误写；不影响原题复盘、答题历史和计时。
- 若有历史错题资产污染，补可审阅的数据修复/迁移方案；不默认删除用户数据。

### P4：回归、设备验收与合并
- 按 AGENTS.md 执行 Red → Green → Refactor，按功能批次提交，并运行全部相关 Playwright E2E。
- 真题训练/复盘、专项合集、资料分析综合、逻辑、数量全部在 iPad 横屏、iPad 竖屏、桌面及手机宽度检查。
- 最终候选 HEAD 完成 CI 与关键场景实机核查，审阅通过后才合并；不直接推 main、不自动部署。

## 6. 非目标、风险和审阅点

**非目标**：本计划 PR 不改代码；实施时不重写出题引擎、不迁移数据库主存、不修改题库 Markdown 原文、不重新设计真题 AI 聊天、不自动部署、不合并到 main。

**主要风险**：
- 已共享的 StudyGoalBars 因不同容器宽度呈现不同效果；修复应针对根因，不加第二份 CSS。
- split_resize.js 的本地存储名称和手势原为 question-bank 设计；跨模式复用需要兼容旧偏好并排除与翻题/手写冲突。
- 真题与 AI 题的交卷/历史数据契约不同；强行共用业务状态机会破坏恢复和判分。
- “专项训练”这个菜单也包含 AI 生成题；以菜单名称判断资产资格会误建错题或 Flashcard。
- 当前另有 AI 解析相关实现 PR；后续实现时须重新确认 main 与并行 PR 的文件冲突，不能覆盖别人的改动。

**请在本 Draft PR 先审阅的决策**：确认采用“同一共享交互组件 + 各题型保留服务端业务”的方向，以及“**仅真题/入库专项题进入错题库、收藏和 Flashcard；所有 AI 生成题均不进入**”的来源规则。确认后另行在此 PR 继续实施，或按评审意见另开实现 PR；本次绝不把方案当作已完成工作。
