# 专项训练 App 化与统一交互实施计划（2026-11-03）

> 状态：实施中（以 PR 最终测试结果为准）；分支 `feat/training-app-shell-unified-practice-20261103`。
> 目标：iPad 优先的固定视口 App Shell，真正局部滚动；统一真题/专项答题交互，减少重复历史入口；不改变题库正文、FSRS、数据持久化契约、router/camera。

## 产品要求与不变量

1. **固定视口优先**：专项训练根节点与 visual viewport 对齐，顶部与导航不滚走，内容视口 min-height:0/overflow:hidden，只有材料、题干、选项、训练选择和历史列表内部滚动。不得以全局 touchmove preventDefault 代替滚动治理；兼容 iPad WebKit 软键盘、安全区、横竖屏、缩放。
2. **统一答题操作**：共用上一题/下一题、紧凑底栏、按需展开的答题卡。滑动切题需判别水平意图和阈值；纵向阅读、横向图表、文本选择、Apple Pencil 书写、Pencil 拖拽/缩放不得误切换；边界题不越界；切题保留材料滚动和草稿。
3. **真题选择**：去掉全文搜索及几百项原生 select，改为考试地区/年份分组渐进展开的试卷卡片；题量和候选列表来自后端，不虚构年份、地区、试卷。原卷整卷、单卷模块和跨卷模块各自保持已有语义；一级模块卡片、二级可展开，立即明确已选状态。
4. **可靠性**：开始前验证必选项，前台给出具体原因；网络错误可见；选择答案后不应重载整卷正文。只有可靠答案才能判分，未经核验的题不被伪装成已核验。
5. **不展示开发术语**：将待核/不可判分/未归类的详细技术指标从普通选择页、题面移至题库管理或必要的简明质量提示；不静默把无效题当有效题。
6. **历史记录单一归口**：训练入口只展示继续最近未完成任务的轻量快捷入口；完整记录集中在“练习记录”视图，按来源/状态过滤，保留原模块查看历史解析和恢复原题的能力；不同源的 ID 必须带 namespace，不能以日期或标题合并。现阶段不迁移/合并存储数据，模块原生统计与作答数据保留。
7. **视觉系统**：保留现有暗色粉色设计，统一标题、卡片、间距、按钮、空态/忙态/错误态，不重复造业务组件。

## 代码实施分层

- `web/pages/training.rs`：固定训练外壳、统一顶层入口与记录入口。
- `web/pages/training_setup.rs` 和 `frontend/app.css`：复用固定顶部、内容滚动、底部操作区域；小屏适配与可访问性。
- `web/pages/question_bank_practice.rs`：原卷渐进式卡片、模块展开；题干/材料左、选项右；答题卡抽屉、手势切题；最小化整卷网络往返；必要反馈。
- `web/pages/comprehensive.rs`、`logic_judgment.rs`：复用公共交互能力时应维护题型特有的材料与草稿语义，优先针对已有多题导航集成。
- `e2e/question-bank.spec.ts`、相关 training/logic/analysis E2E：从下拉选择变更为卡片流程，增加固定视口、题号抽屉、滑动、答题恢复/计分/标注不受干扰测试。
- `.github/workflows/portal-ci.yml`：对 PR 的 Playwright 仅运行相关训练场景；仍执行 frontend bundle、格式/静态/单元/Clippy。主分支 push/手动仍保留完整 E2E。PR 上的最终候选 HEAD 必须通过所有相关检查。

## 验收

- [ ] iPad 横屏/竖屏：document 无纵向滚动，材料与选择/选项独立滑动，固定顶栏/底栏不消失。
- [ ] 真题选择：无超长下拉框/默认搜索；分组、展开、选择、开始、切换模式后清理无效选择。
- [ ] 原卷模块：不丢原始题号和共用材料；答案安全、可保存、续答、提交、复盘。
- [ ] 120 题页面底部不再常驻完整题号，抽屉可选题且可关闭。
- [ ] 手指左右滑动切题，笔写不切题，文本/横向图表不误触。
- [ ] 多来源历史记录不在各个训练设置页重复展开；已有记录仍能继续/复盘，统计不重复计数。
- [ ] Playwright PR 相关套件完成，相关格式、静态、单测、Clippy 全绿；PR 合入主分支后核对 merge commit。
- [ ] 无需升级/迁移题库 SQLite 或 FSRS；不触及热部署与设备。

## PR/CI 策略

遵守仓库 AGENTS.md：分支 + PR，测试先红后绿，批量提交减少不必要 CI 次数。只缩减 PR Playwright E2E 范围，**不放宽必需的检查**。任何检查失败须先修复并在最后候选 HEAD 重新验证；不能提前宣称完成或合入。
