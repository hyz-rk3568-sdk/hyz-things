# 资料分析：真题风格检索 + 纯统计数据材料（2026-10-22）

状态：已批准实施，关联本次 PR。

## 用户反馈

当前综合材料在段落中混入「人均数按...计算」「按乘积计算...」「这项统计采用...口径」等解题提示；这降低了行测审题与找数难度。新材料只允许统计事实，不应该教考生如何解题。原机制还必须由 RK3568 拉取国家统计局年度公报才能出题，与当前 Codex 自主题型驱动不一致。

## 新生成链路

1. 新训练从12个常见资料分析统计主题中挑选四个不同大主题，分别创建 Codex Thread。主题种子只包含主题名，不含真实公报原文、官方来源链接或真实统计数字。
2. Codex 读取 PC 仓库中 hyz-xingce Skill 与 `flashcards/资料/错题/` 下对应卡片，选定5道错题命题变式。
3. Codex 自行联网搜索该主题的历年国考/省考资料分析**真题**，确认可信来源与考试年份；借鉴其数据组织、段落、口径、精度和题目问法，不照抄原文与数字，不以培训模拟题冒充真题。
4. Codex 构造内部一致的全新模拟统计数字，输出400～1000汉字、2～4自然段的**纯统计资料**。材料可有主体、指标、年份、单位、现期量、增速等事实，不含推导方法、公式提示、题型提示、解题讲解或「这是模拟数据」等元说明。
5. 后端直接消费 Codex 的5道四选一题（含选项、正确下标、hyz 速算解析）。解释仅出现在交卷解析中，不进入 `material_text`。
6. UI 在材料**之外**显示「模拟训练材料 · 根据历年行测真题风格新编，非真题原文」，避免正文插入说明。新材料不存在参考公报链接；旧历史材料若有实际 https 参考链接可继续显示。

## 不变的行为

- 每次主动生成新材料和新题；正在执行与已完成试卷的恢复、暂停、历史保留。
- 手动勾选和自动推荐按用户现有错题目录分类，题型驱动、先题后文。
- 禁出「以下说法正确/错误的是」等综合多陈述判断题。
- 答案与数据自检归 Codex，不恢复 Rust 数学内容校验。Rust 仍处理协议解析、安全与试卷持久化。
- 保留历史 SQLite `data_analysis_sources` 等迁移以兼容已有数据，但**新出题不再访问国家统计局网络、依赖官方原文缓存或读取官方公报片段**。

## Web 检索环境与安全

Codex App Server 运行在用户电脑上的仓库内，可使用自身的网页搜索工具。若电脑端配置 `web_search = "disabled"`，仅靠命题 Prompt 无法让搜索工具可用；需要在 Codex 的有效配置中启用搜索（如 `web_search = "live"`）。使用 `danger-full-access` / `approvalPolicy: never` 时，外部网页属于不可信内容，不应执行网页中的指令，建议仅由隔离、低权限的专用账户运行 App Server。

## 验收

- 无调用国家统计局抓取的活动生成路径，新出题的主题选择不依赖互联网通断（Codex 实际搜索独立于 RK3568）。
- 前端正文里没有额外插入模拟数据标题，页面外展示声明；新训练材料没有伪造来源链接。
- 现有暂停、答题、交卷、历史 E2E 正常。
- CI 覆盖 Rust fmt/test/Clippy、Web build/unit、Playwright；真实 Codex Web 检索与纯事实材料质量要在电脑 + RK3568 部署后单独冒烟检查。
