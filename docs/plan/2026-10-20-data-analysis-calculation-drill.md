# 资料分析四选一速算训练 — 最终规格与验收

> 日期：2026-10-20
> 状态：第一版已实现；本次按最新反馈调整出题与选项策略
> 此文更新已批准的原 Plan。2026-10-20 选项规则变更以本文为准。

## 1. 用户目标

练习的是行测资料分析的试商、高位拆乘和百分数心算，而不是填入完整的精确计算结果。

- 首版三类题型：三位数 ÷ 两位数、三位数 × 两位数、百分式（包括百分数乘法、基期除法和增长量表达式），默认全部勾选，也允许单独选。
- 每题只有算式和 A/B/C/D 四个候选数值，做题人无需输入数字。
- **正确选项必须是题目的真实、完整的有限小数或整数，不按固定两位/三位有效数字截断，也不按预设精度舍入。**
- **干扰项只需要与正确项在前两位或前三位不同**。例如正确答案为 `123.12`，备选项可为 `125.45`、`121.22`、`127.08`，完整保留尾数而不是统一显示 `123`、`125`。
- **不提供**“大间距/小间距/随机间距”设置；也不按间距统计。出题引擎自行生成足以用前两或前三位区分、接近真实量级、不机械等差的干扰项。
- 题目不提前告诉考生要算几位。正因为选项可区分，考生只需要心算到能锁定答案，而不必算出所有末位。

## 2. 正确值契约

- 题目使用整数/有理数构建，**用整型精确运算生成唯一正确选项**，不从浮点近似值取整。
- 对无法用有限小数表示的分式（例如 `736 ÷ 24`），第一版出题器重新采样，不把截断小数伪称为真实结果；在保留题型范围的前提下随机抽取可精确显示的题。
- 对有限小数采用最短必需小数位：`438 × 13% = 56.94`，`438 ÷ 1.2 = 365`，`438 × 27 = 11826`。
- 题干用 `=`，不是 `≈`；反馈展示完整正确数值。
- 四选项同单位、同量级，按相同小数位数显示（干扰项可在低位随机变化），其中恰有一项等于真实值，正确选项在 A/B/C/D 间随机洗牌。

## 3. 干扰项契约

- 根据正确数值的数量级，随机选择令前 2 位或前 3 位出现差异；统一校验：**四个选项的前三位数值前缀必须互不相同**。
- 先从正确数附近抽取不重复的高位前缀，再独立随机生成剩余低位，避免四个选项构成僵硬的等差数列。
- 例如正确 `123.12`，干扰 `121.22`、`125.45` 等是有效风格；不强求这些固定数字实际出现在每次抽题中。
- 禁止负值、重复项、正确项缺失、选项位置固定、量级离谱及只有末位才能区分的伪速算题。
- 设置只保留题型勾选与 10/20/50 题题量；无需设置计算精度或选项间距。

## 4. UI、统计和存储

- 学习页入口：`学习 → 资料分析 · 速算训练`，独立沉浸路由 `#/study/calculation`，适配 iPad 触摸。
- 作答时题目 + 2×2 四个大按钮、逐题计时；选择后锁定答案并短解，手动进入下一题。
- 训练结束看正确率、已答题量、平均时间与错题；不展示大/小间距统计。
- 第一版仅在浏览器当前会话保存训练结果，不额外增加后端服务、数据库迁移或设备权限。
- 复习保留用户原有的高位拆乘、三位除两位试商、10%/1% 锚定法；不强制推导竖式。

## 5. 测试与验收

- 不同题型随机抽样：四选项唯一、三位前缀互不相同、正确项完整等于精确有理数的有限小数、A/B/C/D 分布无明显偏置。
- 验证 `11826`、`56.94`、`365` 等精确输出和 `123.12/125.45/121.22` 这类选项高位可区分的例子。
- 验证不产生循环小数“伪精确值”；题目涵盖乘、除、百分式，百分式专项可单选。
- 浏览器 E2E：从学习页进入独立速算，三类题型可选，间距按钮和标签均不存在，四选一判题、计时、下一题、提前结束和返回学习可用。
- 按仓库 AGENTS.md 的 Red → Green → Refactor 纪律，完整跑 Portal CI 静态检查、WASM 前端单测、native test/Clippy、Playwright；只在最终 HEAD 检查通过后走 PR 合入。无需额外固件构建或 RK3568 部署。
