# 资料分析找数专项：共享材料与跨模式去重

## 目标

- 学习 → 专项训练新增「找数训练」。
- 综合训练保持 4 份 × 5 题 / 20 分钟；找数训练每份 5 道定位题，不计算、不看选项。
- 复用现有国家统计局年度公报提取、Codex 改写、综合训练材料缓存、topic/subtopic 分类。
- 新增定位题由 Codex 输出，程序验证证据锚点、完整数字及精确字节位置。
- 一份材料展示后，两种模式共用已见记录。旧综合训练 active/submitted 会话补记已见；仅出题未开始不算已见。
- 默认只抽陌生材料；允许手动开启复练。新材料耗尽时明确提示。
- 找数答案、每题耗时、状态独立保存在 SQLite，不更改综合训练成绩与 FSRS。

## 数据边界

- 保持 data_analysis_groups 保存已校验综合材料与计算题；定位集 data_analysis_locating_sets 按 group ID 缓存。
- data_analysis_material_seen 用来源网址 + 公报章节的保守身份合并视图。当前会将同章节的不同 AI 改写视为同一材料，宁可过度排除，也不把重复原始统计事实冒充陌生材料；以后可按经验证的官方片段指纹细分。
- data_analysis_locating_runs 保存 questions_json、answers_json、耗时与完成状态，数字位置仅在服务端判题；前端只收到题干和可点击原文。
- 请求遵循既有管理员会话、同源/CSRF 与工作队列控制。开始读取材料时才记已见。
- AI 锚点必须是材料中唯一的连续片段，且题干、锚点都包含主体及指标，数字只能是完整 token；服务端记录 UTF-8 字节区间并按位置判分，不只是比较数值字符串。

## 来源校验边界

沿用现有官方数字存在性验证及计算校验。新增定位校验针对改写后材料的精确位置。完整的统计语义对齐（来源主体/年份/口径与改写句逐一对应）仍不能只凭数值集合验证，需要后续结构化事实审核；不能将位置校验误称为完整来源语义校验。

## 验收重点

1. 同一材料 5 题，前两题形成位置地图，后几题复用。
2. 同值不同位置按位置判分；锚点重复、数字子串和主体/指标不一致会被拒绝。
3. 综合训练开始后，找数默认排除同官方章节；旧 active/submitted 综合记录追溯标记。
4. 找数开始后，综合训练准备也排除对应章节。
5. 手动复练可使用已见材料；新材料耗尽不静默重复。
6. 每题耗时与正确率独立保存；刷新后可恢复。
7. 综合训练 20 分钟计时、4×5 计算及入口保持不变。

## 验证

按根 AGENTS.md 在独立分支与 PR 中批量验证相关 Rust 静态检查、native 单测、Web 检查与 E2E；再人工核对 iPad 长材料的数字点按行为。
