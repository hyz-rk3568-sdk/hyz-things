# 申论小题：按任务、材料和文体组织采分

小题先读“要求”确定目标对象、任务动作、限定范围、字数及是否要求公文格式，再对照给定材料。

## 题型与分析

- 归纳概括：列事实/表现/特点，合并同义项；保留能区分采分点的对象、条件和结果，不靠套话填字数。
- 综合分析：明确题干要求解释、评价、比较还是阐述关系；交代是什么、为什么及必要的影响/对策，避免只抄一段材料。
- 提出对策：问题与对策一一对应，写清实施主体、可执行动作、对象和约束；没有材料支持的政策工具不可编造。
- 贯彻执行/公文写作：先落实文种、写作对象、场景、语气和目的；标题、称谓、正文、落款等格式由题意决定，不机械扣“缺固定标题”分。
- 其他：以题干任务为准；不能只因题号是末题就判定为作文。

## 评分提示

每个评分点用一段材料证据或能够定位的原始事实支持。正确的同义概括与合理归纳应可命中；命中部分重要限定给部分分，出现反向事实应标注冲突。字数与格式是否影响评分，必须以题干明确要求和评分 schema 为准。

不假定某位老师的答案是唯一标准；材料与参考答案有冲突时优先还原材料含义，向用户标注分歧而非强行“统一口径”。
