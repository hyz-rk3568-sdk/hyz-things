# 申论小题：审题—找点—加工—应题—表达

本文件结合现有申论练习规则和白鹭方法论中的「有问有答」「非仅缩写，视为应题」「前置提炼」「3W 中好坏策」「对策抓手」。这些**用于提高审题和采分判断的质量，不是官方硬性赋分规则**。有争议时以本题题干、相关材料和实际表达为准，避免因为未采用某位老师的写法而机械扣分。

## 1. 审题与预判

先提取 **作答对象、任务动作、限定范围、特殊要求、字数、文种、身份和受众**。分类要结合「问什么」和「问的对象是什么」，不能只凭「谈谈」「分析」等泛化动词判断，更不能依赖第几题来定题型。

- 「原因/为什么」常涉及归纳原因，但必须结合题目要求与材料判断，**不套用“100% 概括题”**。
- 「理解/认识」要重点解释含义和逻辑；「评价/评析/谈看法」还要检查题干是否要求作出态度判断；「观点明确」则优先检查有没有直面评价对象的观点句。不能一律要求同意/反对。
- 字数可用于规划要点数量和每点篇幅。白鹭提出的「约每行 25 字」「概括或分析约每 2 行一项、对策约每 3—4 行一项」是**考场草稿估算**，并非固定句数、阅卷规则或自动扣分条件。
- 题干明确要求「对应」「分别」「对比」等关系时，需要在答案形式中体现；若仅要求「针对性」，不必把所有问题与每条对策强制一一配对。

## 2. 材料找点与加工

先依据整段语义判断哪些事实或结论应保留。可将「重复关键词、首尾句、最高级、标志词、代词还原、冒号/破折号、总分关系」作为**搜索线索**，但不以出现次数、标点或段落位置直接认定必得分点。

- 同义要点可以归并，**不同类别、不同主体或各自独立计分的信息不得误并**；一段材料可能有多个要点，多个段落也可能属于同一要点。
- 白鹭强调「据数预判、就近合并、宁拆勿并」：字数有限时有策略地合并，既避免无意义重复，也不要因过度压缩而丢掉有区分度的限定条件和实施细节。
- 「前置提炼」应准确概括本段内容，并在题干要求条理清楚、分类说明或字数受限时发挥作用。提炼词可以来源于材料关键词、动宾结构或名词短语，不能生造政治化标签、覆盖正文没有的信息。
- **不写前置提炼不等于没写采分点**：如果正文清楚、完整地表达了该项内容，不因缺少概括小标题重复扣分；反之，只有漂亮提炼词但正文缺核心事实，也不能虚给分。
- 检查代词指代、主体与条件是否说清楚；对比题要检查同一维度下 A/B 的具体差别，不能只分段罗列 A 和 B 的现象。

## 3. 各题型评分补充

### 归纳概括

以「所问对象 + 完整的事实/表现/原因/特点」为核心。重视覆盖要点与分类的准确性，确认正文能否与题干直接连起来读通顺。对于要求「差异、变化、不同」的题，按差异维度进行 A/B 对照更清晰；**是否实际影响得分仍取决于遗漏或混淆了什么关系**。

针对「争议焦点」等多主体观点题，可按双方争论的议题配对归纳；不因缺少某种固定标签而否定材料支持的正确内容。

### 综合分析

先确定是解释含义、评价观点、分析现象，还是阐释关系，而不是看到「分析」两个字就套通用模板。

白鹭的 **「中好坏策，有谁写谁，不必求全，依序排列」** 可用于检查材料逻辑：含义/背景（中）、意义（好）、问题与原因（坏）、必要的对策（策）。只有材料与题目要求支持时才写相应环节，不强制每题 3W 齐全，也不以缺少某个环节直接扣分。解释题重点核对原话语义，观点评价题重点核对是否清楚判断并论证。

对划线句、特殊名词的解释，优先回看附近的同义解释、前后文、重复出现位置及相关总结段，不能凭想象编意义。材料已经列明的对策可以引用；是否还需要反推对策，须看题目任务，不能让对策喧宾夺主。

### 对策建议

对策不仅判断方向，还要检查 **问题对象、执行主体、可执行动作、落实抓手、适用条件和预期效果** 是否在题目和材料允许的范围内说清楚。

- 材料直接提供的有效对策优先；根据问题合理推导的措施要有依据，**不得编造不存在的机关职权、政策、数据或过细的操作细节**。
- 对策应具体，避免只有「加强管理」「完善机制」之类空话；但如果材料本身就只支持概括性措施，也不能为了显得具体而虚构抓手。
- 题目若要求分别提出对策或问题与建议「对应」，必须体现关联；仅有「有针对性」的要求，不推导出逐条一一配对的格式义务。
- 对「梳理问题并提出措施」的两问式题，分别检查两个任务；若仅让提出建议，问题描述可精练，把篇幅留给有材料依据的操作建议。

### 贯彻执行／应用文

先核对**格式、身份、目的、特殊要求、场景**（白鹭的审题「五把钥匙」）。再据题型要求决定信息组织方式，可选择讲逻辑、讲时间顺序、讲过渡、讲事件经过或按题目分层，**不强迫所有文种使用同一种结构**。

对倡议书、工作汇报、经验交流、考察报告、通知通告、讲话稿等，要检查实际写作任务要求的是经验、介绍、分析、动员还是可执行建议，明确受众、口吻及重点。标题、称谓、正文、落款等按题意决定；无明确格式要求时不机械扣固定格式分。也不能仅凭文种就断定对策必须占固定篇幅。

## 4. 批改中的结构与分数边界

- **内容采分先行**：每项得分应有题目与材料依据，认可同义概括及非模板化但有效的表达。
- **应题意识另做诊断，不另开重复扣分池**：如对比题没呈现差异、分析题没回应解释对象、对策缺有效做法，应指出哪些关系/要点因此缺失；若已在采分点中扣过，不再为「结构不佳」扣第二次。
- **前置提炼与条理清楚只在真实影响理解时影响分数**。白鹭有关提炼词固定 1—2 分或缺失时的分数上限，只作为可能的教学经验，不直接应用。
- 字数、格式和语言规范按**题干要求及真实影响**评价，不臆造阅卷统一扣分细则。
- 保留有效句子，对缺失信息提出局部改写，说明补在什么位置、来自哪段材料；不默认重写完整答案。
