# 大作文：立意、论点、论证与结构的练习诊断

依据本题作文要求、相关给定材料和学生原稿综合分析，而非预测真实阅卷分数。吸收白鹭方法论中的「破局八部」「拆—近—扩—补」「四张皮」「开引连点」等**有条件的写作与阅读技巧**：用于发现问题和指导改稿，不能替代本题立意和材料证据，也不形成固定作文评分档位。

## 先定题意与立意边界

读完整题干与相关材料，核对：作文主题、指定文体、命题/半命题/自拟标题、立意范围、写作对象、字数要求、是否要求结合某句话或特定材料。不要用脱离本题的时政口号取代真实主题，不虚构材料外政策、数据、人物事迹或案例。

- **立意与切题**：标题、开头、总论点和主体论述是否回应核心命题；是否只抓住材料的边缘现象，或者把材料中一组有关系的主题割裂开来。
- **总分论点关系**：分论点是否真正服务总论点、相互区分且互补；不写互为同义词的三个标题。题目具有双要素关系时，注意解释两者关系，不机械硬凑「A / B / A+B」三个重复分论点。
- **分论点选取**：可参考白鹭的「拆—近—扩—补」——先尝试拆解题干中的并列/关系要素，再考察命题相关材料中的现成逻辑，再适度概括相应材料，最后才审慎补充有依据的角度。其顺序是**寻找写作方案的启发式**，不是禁止其他合理论点或要求必须找满三个分论点。

## 六类核心诊断维度

| 维度 | 看什么 | 可操作的检查 |
| --- | --- | --- |
| 立意与题意 | 标题、总论点、分论点是否扣住题目要求 | 找出文章真正论述的中心，与题干主题词逐项对应 |
| 结构与完整性 | 开头、论述主体、过渡、结尾是否形成完整论证链 | 检查段落关系、重复/断裂、是否有合理收束；允许两分论点、三分论点、纵式等多种组织 |
| 论证深度 | 分论点是否有说理过程，而非只喊口号 | 看是否包含可核对的事实/材料例证、因果解释、比较或反驳，例子之后有无回到分论点 |
| 材料运用 | 引用、概括、案例是否准确支持观点 | 不把材料中相关的事例拼贴为无关联的论据；不杜撰政策和数据 |
| 观点关系与层次 | 总分论点有无交叉、偷换概念或简单重复 | 标出每段段旨句、核心论证与结论，判断是否各司其职 |
| 语言与文体 | 用语准确、连贯，符合议论文及题目具体要求 | 检查语病、口号堆砌、过度抒情、空泛政治背景与明确字数限制 |

「完整性、立意、首尾句、论证深度」可借鉴白鹭的「四张皮」作为**依次阅读和定位问题的顺序**；不能因此认定阅卷老师一定只看这些部分，也不能据其经验断言某个部分缺失就必然低于固定分数。

## 分段诊断与局部改写

### 标题与开头

- 标题是否直接体现命题主题，避免只追求对仗而模糊概念；全命题题目按其具体要求使用标题。
- 开头应尽快引入核心观点，并与下文有逻辑关系；白鹭的「开—引—连—点」（政治背景—依据—联系主题—点明观点）是**可选写法**，不作为唯一高分模板，也不要求政治背景开头。
- 检查开头是否过长、只堆政策名词、虽有华丽词句但没有明确论点。可以在不丢掉真实立意的前提下缩减背景，补一句与题目直接相关的主张。

### 分论点与主体论证

- 检查段首是否明确本段中心，段尾是否回扣分论点；相邻段是否重复同一关系。
- 可采用「分论点 → 原理/因果分析 → 材料或事实例证 → 回扣分论点」的论证链作为检查工具，**不强制每段严格四句或每段都有事例**。
- 「有事例但没分析」「只有原因却跳到对策」「只有政策术语却无材料落点」需要指出具体原句和可补充的推理桥梁；论证是否充分比有没有套用某段格式更重要。
- 对策段要服务文章论证任务：说明为什么有效、条件是什么，必要时可结合材料例证；不机械要求所有议论文对策段占固定行数，或把「必须写对策」当成统一标准。

### 过渡与结尾

- 过渡段是结构工具，不是必选模块。缺少单独过渡段但文章逻辑顺畅，不应扣分；存在论述跳跃才说明应在哪里增加承接。
- 结尾检查是否对核心主题和前文论证作出收束；篇章明显残缺、题目明确要求未满足时说明影响。**不能直接采用“缺结尾不超过 20 分”“结尾阅卷只看有无”等固定阈值**。
- 避免使用没有真实语义的万能结尾、固定政治套话或伪造的名言。可以给一两句贴合本篇主题的局部修改示例。

## AI 批改应如何给分

1. 先判断是否掌握中心立意及其材料支持，再评估论证、结构、例证和语言；不能只按关键词或机械数段落。
2. 对作文的明显短板，指出**文章真实原句与对应段落**，解释它为什么妨碍切题或论证，并给出最少量但最有效的修改方向。
3. 同一问题不重复扣分；例如一段偏题造成论证材料失效，可解释多重影响，但不要重复算成几个无关惩罚项。
4. 若题目提供可信满分，可以给出**透明、非官方的练习参考分**；不把白鹭老师的示范评分阈值、篇幅比例、时间分配等经验冒充官方评分表。没有可信满分只给维度诊断。
5. 先指出原稿最值得保留的观点和真实例证，再列最影响质量的 2—3 个问题。默认**提供局部改写，不生成整篇替代范文**，除非用户明确要求。

## 练习时可用、评分时不能强制的经验

「短而有力的开头」「根据材料选两个或三个分论点」「紧扣题目主题词」「段落首尾交代逻辑」「考场时间配置」「拆近扩补」均可帮助复盘。题目与材料优先；**不能因为未使用某个老师的模板、未凑三个分论点或未达到所谓黄金行数，就直接扣分。**
