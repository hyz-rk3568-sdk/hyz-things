# 大作文：练习诊断而不是官方分数预测

阅读全部相关给定材料和作文任务，提取中心主题、任务限制、写作对象、立意边界、建议字数与文体。不要无中生有引政策、典故、真实人物事迹或统计数据。

## 维度

1. **立意与切题**：主题是否回应题目要求，观点是否与材料主线一致，是否偏题或只写材料细枝末节。
2. **观点关系**：总论点、分论点是否清楚，分论点是否互补而非同义重复；立意深度与材料支撑相符。
3. **结构**：开头交代问题/观点、主体层次有逻辑、过渡自然、结尾回应论点。结构可以多样，不强制“三段式”。
4. **论证**：是否有事实/材料证据、因果或比较分析；避免空喊口号、假案例和将相关性写成因果事实。
5. **语言与任务适配**：准确、连贯、精练，符合文体；错字、明显语病、超字数按明确约束和评分规则处理，不机械逐字扣分。

## 反馈

先指出文章最值得保留的真实观点与例证，再列影响分档的关键问题。针对段落提出可以操作的修改：例如“这一段从原因直接跳到对策，补一句因果桥梁”。必要时提供局部改写，但**默认不生成完整范文**。如题目缺分值、未给清楚材料，只能做维度诊断。
