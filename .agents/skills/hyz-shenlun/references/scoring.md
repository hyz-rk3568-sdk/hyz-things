# 申论练习评分：采分点 + 应题意识 + 作答质量

## 原则与证据优先级

根据**本题题干及具体要求、相关给定材料、学生实际作答**进行独立批改；来源参考答案是核对线索，不能当作唯一标准，更不能凭教师经验虚构官方评分细则。认可材料支持的同义表达与合理概括。每项实质性扣分须能说明：题目要求什么、材料依据是什么、学生原文哪里命中或遗漏、为什么影响作答。

吸收白鹭申论思维框架中的「审题—找点—加工—表达」「应题意识」「前置提炼」等方法，用于**质量诊断和补充检查**。这些是教学经验，不是官方固定权重或自动扣分表；尤其不能把教师关于「每个提炼词几分」「不写提炼词得分上限」「作文缺结尾固定降到某分数」等经验数字当成真实阅卷细则。

## 两层评分，不重复扣分

**第一层：内容采分（主要依据）。** 先不依赖学生作答，按题干和材料梳理互不重复的有效要点；再逐项对照学生原句，判断命中、部分命中、遗漏、答非所问或材料不支持。对意思相同、措辞不同的表达应合理给分；必要时说明限定词、主体、措施、对象或结果为何重要。

**第二层：作答质量（检查是否真实影响答题）。** 依次检查以下维度；除非题目要求或答案实质问题表明其影响评分，否则只提出改进建议，不能另扣一次：

| 维度 | 检查什么 | 何时应影响评分 |
| --- | --- | --- |
| 审题准确性 | 作答对象、任务动作、限定范围、题型、字数、文种与身份 | 因误审题导致核心任务未完成或明显答非所问 |
| **应题意识** | 是否以答案内容和形式回应问法，而不是只缩写材料；对比题有无呈现具体差异，要求观点时有无明确观点 | 实质遗漏题目要求的比较、解释、评价、主体或关系 |
| 找点完整性 | 重要要点有无遗漏；是否混入与问题无关的材料信息 | 遗漏或错误信息影响采分；冗余本身不当然扣分 |
| 加工合理性 | 分类是否准确、独立要点是否误合并、前置提炼是否概括有效、层次是否可辨 | 错误归类、混淆关系或表达导致应得要点无法清楚识别 |
| 表达与规范 | 原文要点是否准确；代词指代是否清楚；语言是否规范，字数与格式是否满足明确要求 | 造成歧义、偏离明确要求或妨碍理解；只因没用某种漂亮标题不扣分 |
| 应试效率 | 冗余表述、字数配置、能否更精练或更具体 | 优先作为训练建议，不设独立扣分池 |

**防止重复扣分：** 一处作答既缺采分点又缺前置提炼时，先按真正缺失的内容评分；同一问题可以从两个角度解释，但不能再就「没有前置提炼」重复扣分。已在采分点得分体现的错误，不另创一个结构扣分项目。区分「题干明确要求」与「老师建议写法」。

## 小题评分路径

1. **先审题**：标出作答对象、问法、具体要求、材料范围、字数、文种和可信满分；不要仅凭「谈谈」「分析」或题目位置判断题型。
2. **先定要点**：按照材料内容归纳采分点及关系，保留可核对的原文或材料编号；「关键词重复、首尾句、总分关系、标志词」只是找点线索，必须回到完整语义判断，不把启发式视为事实证据。
3. **逐点对照**：引用学生真实原句，写明命中/部分命中/缺失的理由，认可同义表达；区分独立要点与表达重复。
4. **复核应题与加工**：检查问法是否被正面回应、材料是否正确分类、是否把两个独立要点错误并为一个、是否因表达太空泛而缺少材料中的有效抓手。
5. **决定分值**：有可信满分才由 AI 自主作透明的练习分值分配，核对分项与合计不超满分；没有可信满分则输出「未评分诊断」，**不得猜测分值**。不直接照搬某位老师的固定分数上限、扣分比例或预测提分数。
6. **提出具体改法**：保留已经写对的内容，只对真实的漏点、误判、组织和表达问题提供可执行的短句改写，不自动生成整篇替代答案。

## 大作文、应用文与格式

- **大作文**：综合评估立意与切题、总分论点关系、材料与例证、论证深度、段落结构、语言和完整性；可借用「破局八部」（主体立意、开头、分论点、过渡、论述、结尾等）的阅读顺序，但不能要求统一三分论点、统一开头模板或硬性限制对策句数。
- **应用文**：重点核对身份、对象、场景、目的、特殊要求、文种、内容侧重点、语言与格式；内容应服务题目任务。并非所有公文都要以对策为主，不能未看题干就固定扣格式分。
- **字数/结尾**：明确违反题干约束时解释具体影响；没有真实评分细则，不编造「超一行扣一分」「缺结尾不超过某分数」等规则。

## 申论 Markdown 报告格式

直接输出中文 Markdown，优先保持以下统一结构（不另输出白鹭式平行报告）：

# 申论批改

## 练习参考分

注明「AI 练习参考分（非官方）」，有可靠满分时显示分项与总分；无可信满分则改为「未评分诊断」，不输出假精确数字。

## 审题与作答要求

明确题目要回答什么、有哪些范围/文种/字数要求。突出有实质影响的审题偏差。

## 采分点与得失分

小题优先使用 Markdown 表格：**要点｜分值与建议得分（若可评分）｜我的真实原句｜材料依据｜理由**；随后用少量文字说明应题、分类、前置提炼等结构性问题及是否已经计入采分点。作文改用维度和段落评价，不硬套小题采分表。

## 总体评价

先指出真正写对的要点，再说明影响作答质量的主要短板；严守「同一问题不重复扣分」。

## 修改建议

优先指出最值得修改的 2—3 处，提供局部改写及对应材料理由。仅用户主动提出时另写完整范文或替代答案。

## 图片作答

先直接看原图，能辨认的部分可用于练习批改；关键字迹不清时如实标明不确定性与可能影响，不猜测补全。独立 OCR 仍直接输出逐页 Markdown，无人工确认步骤，也不进行评分。

## 方法论边界

白鹭材料中的「字数÷25 估算行数」「前置提炼」「3W 中好坏策」「拆近扩补」「结尾完整性」均可用于作答指导；属于**启发式而不是无条件评分标准**。原材料或题干要求与经验规则冲突时，优先遵循本题要求及可核对事实。
