# 行测做题（hyz）

此 Skill 是 hyz 自己的行测做题套路的统一入口。按题型按需读取相应文档，不要用泛化解法覆盖用户自己的思路。

## 文档导航

- **资料分析**：读取 [references/资料分析.md](references/资料分析.md)。以 `flashcards/资料/` 当前八份源卡为准，包含扫材料→审题→看选项→定位→最低成本算法→确定就停→考场不回头，以及假设代入、分数比较、线段混合、年均变化、份数法、尾数/试商与误差控制。
- **判断推理 → 论证推理**：读取 [references/论证推理.md](references/论证推理.md)。涵盖论点与论据、横向/纵向对照、由果推因、削弱、加强、前提假设、否定代入。
- **判断推理 → 逻辑判断专项范围**：先读 [references/逻辑判断.md](references/逻辑判断.md)，确认考点和训练排除项。训练仅含论证推理（含原因解释）、形式推理（含翻译、真假、集合、平行结构）、分析推理（排序、位置、对应匹配、分组选择）；不含图推、定义、类比、日常结论、多条件综合题组。
- **判断推理 → 形式推理**：读取 `flashcards/判断/形式推理/card.md`，已有用户规则优先，新增标注“基础通用规则”的卡仅作待复盘起点。
- **判断推理 → 分析推理**：读取 `flashcards/判断/分析推理/card.md`，先按题型选择排序、位置、匹配、分组的基础卡，后续用户复盘方法优先。

## 使用规则

1. 先判断题目属于哪个模块，再完整读取对应文档；多模块题目可同时读取。
2. 做题套路的事实来源是本仓库 `flashcards/` 下相应卡片；用户明确说「使用我的套路」时，先检索相应 flashcard。仓库源卡变更时应复核参考文档是否需要同步。
3. 用户已有计算或推理过程时，尊重原有方法与术语；只纠正确实的计算、抄写、逻辑错误，资料分析合理近似不应擅自改为长算。
4. 对于未覆盖的模块，明确说明尚无 hyz 专用文档，不得把通用知识伪装成用户的方法。
   新增基础卡若注明“基础通用规则（待实战复盘）”，不得归因为 hyz 个人独创或已验证的方法。
5. 用户说「转成错题」，严格采用 `# 题目 / ## 我的思路 / ## 错误点 / ## 修正 / ## 复盘`，保留原思路。
6. 用户说「转成 flashcard」，给 Markdown 源码，采用 `## Card / ### Front / ### Back / ---`；遵循用户已有公式格式约定。

今后扩展其它题型，在 `references/` 新增独立 Markdown，并更新本导航即可，不必新建一个 Skill。
