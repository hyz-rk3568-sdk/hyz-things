# 行测做题（hyz）

此 Skill 是 hyz 自己的行测做题套路的统一入口。按题型按需读取相应文档，不要用泛化解法覆盖用户自己的思路。

## 文档导航

- **言语理解与表达**：读取 [references/言语理解.md](references/言语理解.md)。按逻辑填空、中心理解、语句填空、下文推断、语句排序、细节判断、关键词提取选用对应技巧；先读文段并预判，抓观点主体与上下文对应，再对比择优。当前仅有词语辨析积累卡时，可按需查阅 `flashcards/用户整理/言语理解与表达/词语辨析/cards.md`；不要将课程方法误称为 hyz 个人原创。
- **资料分析**：读取 [references/资料分析.md](references/资料分析.md)。以 `flashcards/用户整理/资料分析/` 当前八份源卡为准，包含扫材料→审题→看选项→定位→最低成本算法→确定就停→考场不回头，以及假设代入、分数比较、线段混合、年均变化、份数法、尾数/试商与误差控制。
- **判断推理 → 论证推理**：读取 [references/论证推理.md](references/论证推理.md)。涵盖论点与论据、横向/纵向对照、由果推因、削弱、加强、前提假设、否定代入。
- **判断推理 → 形式推理解题方法**：读取 [references/逻辑判断.md](references/逻辑判断.md)，按直言、复合命题、组合排列、特殊题型识别适用技巧；可根据题干跨类组合。
- **判断推理 → 形式推理错题卡**：当前形式推理 flashcard 仅有四类错题卡：`flashcards/用户整理/判断推理/形式推理/{直言命题,联言选言假言命题,组合排列,特殊题型}/错题/cards.md`。按题型检索，用于查看个人错题和复盘；解题方法读取上面的 [references/逻辑判断.md](references/逻辑判断.md)，核对课程来源时读取 [references/小P-形式推理-原文.md](references/小P-形式推理-原文.md)。

- **数量关系**：读取 [references/数量关系.md](references/数量关系.md) 判型、选法，再按题型读取 [方程比例与应用](references/数量关系-方程比例与应用.md)、[计数概率与最值](references/数量关系-计数概率与最值.md)、[几何数推与特殊题](references/数量关系-几何数推与特殊题.md) 的统一方法文档；验题与输出读取 [实战验题与输出](references/数量关系-实战验题与输出.md)。优先核对 `flashcards/用户整理/数量关系/` 的个人方法卡。原小P课程摘要已归入上述主题文档，不再单独调用，也不把通用方法冒称课程原话。

## 使用规则

1. 先判断题目属于哪个模块，再完整读取对应文档；多模块题目可同时读取。
2. 原有个人方法卡与错题卡位于 `flashcards/用户整理/`，默认网页真题卡写入 `flashcards/真题练习/{module}/{category}/错题/cards.md`。AI 出题以 `用户整理` 下符合题型要求的已有卡片为来源；不要将真题练习自动归为用户个人方法卡。
3. 做题套路的事实来源按题型区分：用户明确说「使用我的套路」时，先按导航检索相应方法卡或参考文档；有方法卡的模块以方法卡为准。形式推理当前仅有错题卡，个人错题与复盘以错题卡为准，解题方法读取 `references/逻辑判断.md`，课程来源核对 `references/小P-形式推理-原文.md`。不要引用不存在的类别级 `cards.md`，也不要把错题卡当作完整考点覆盖。仓库源卡变更时应复核参考文档是否需要同步。
4. 用户已有计算或推理过程时，尊重原有方法与术语；只纠正确实的计算、抄写、逻辑错误，资料分析合理近似不应擅自改为长算。
5. 对于未覆盖的模块，明确说明尚无 hyz 专用文档，不得把通用知识伪装成用户的方法。
   新增基础卡若注明“基础通用规则（待实战复盘）”，不得归因为 hyz 个人独创或已验证的方法。
6. 用户说「转成错题」，严格采用 `# 题目 / ## 我的思路 / ## 错误点 / ## 修正 / ## 复盘`，保留原思路。
7. 用户说「转成 flashcard」，给 Markdown 源码，采用 `## Card / ### Front / ### Back / ---`；遵循用户已有公式格式约定。

今后扩展其它题型，在 `references/` 新增独立 Markdown，并更新本导航即可，不必新建一个 Skill。
