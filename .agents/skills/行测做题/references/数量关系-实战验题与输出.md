# 数量关系｜实战验题、答案冲突与复盘规范

> 用于 Question Bank 交卷后 AI 复盘、独立答题、个人错题检查与无参考答案题目。本文只定义解题行为和输出，不修改题库、题目状态、作答历史或现有 AI 服务边界。

## 1. 三阶段

**阶段 A：独立解题**

1. 从题干提取所求、全部数值条件、选项及单位；有图先读图。
2. 对照 [数量关系总入口](数量关系.md) 判断题型，优先按个人方法卡选法。
3. 用最短可复核计算得到候选答案；不要先看原参考答案再逆向编过程。

**阶段 B：交叉验证**

- 代回至少一个核心条件，检查单位、方向、完整对象数与整数限制。
- 选项非常接近或有舍入时，用精算替代估算；结论落在两个选项之间就回看数字。
- 多选均满足时，不强行选唯一答案；题目条件冲突或明显缺数时报告存疑。
- 有参考答案：对照差异；如不一致，逐一核查抄录、计算、前提、题面版本及答案来源，不未经核查就声称参考答案错误。
- 无参考答案：明确结果为独立求解，不能叫作“官方答案”或“已判分”。

**阶段 C：按用户目标输出**

- **只问选项**：一句结论 + 最关键关系；内部仍完成校验。
- **要求速解**：先最快破口、两三步计算、一道验证。
- **要求教学**：在速解后补充“为什么这样做”和最可能错的分母/重复计数；必要时给常规方程法核对。
- **批改用户解法**：保留用户第一步至最后一步的顺序，指出**第一处**与条件不一致的位置；尽可能在用户方法内修正。
- **转错题/flashcard**：严格遵循顶层 `行测做题/SKILL.md` 的既定格式，不能自创不兼容字段。

## 2. 有无参考答案的措辞

| 当前证据 | 可用表达 | 禁止表达 |
|---|---|---|
| 原题标出答案且独立解法一致 | “独立验算与参考答案一致” | “已获得官方认证”（如未有官方来源） |
| 原题无答案，计算可验证 | “独立求解得到 C；原题无参考答案” | “官方答案 C” |
| 计算结果与所有选项均不符 | “题目或选项存在待核问题” | 偷改数字以使某项成立 |
| 多项可行/条件不足 | “无法从现有条件确定唯一选项” | 随便选最接近的一项 |
| 图片或公式读不清 | “某数值/图形标记不可读，无法确认” | 猜一个看似合理的数 |

对于无答案的 Question Bank 练习，AI 解析可以提出独立推导，但**不能自动将其视作可信判分键**；是否更新题库应由单独的验证和写回流程处理。

## 3. 题型特定的检验点

| 题型 | 必查条件 |
|---|---|
| 方程 / 不定方程 | 非负整数、解是否唯一、分母不为 0 |
| 经济利润 | 标价 vs 售价、收入 vs 利润、损耗与固定费用 |
| 工程 / 牛吃草 | 工作量固定吗？净增长方向与停工时段 |
| 行程 | 运动方向、同程还是同时、首尾时刻与单位 |
| 溶液 | 溶质是否真的守恒、抽取是否带走溶质 |
| 容斥 / 最值 | 人数 vs 人次、交集层次、极端构造可行 |
| 排列组合 | “不同方案”的定义、顺序与分组等价 |
| 概率 | 样本空间等可能、独立或条件概率 |
| 周期 | 起点、余数位置、首尾日包含关系 |
| 几何 / 数推 | 比例维度、必要图形条件、规律是否唯一 |

## 4. 验收用的代表性小题（非原课件）

用来人工检查 Skill 是否真能选对模型和指出边界；不应自动写入题库或当作课程原题。

1. **两类计量**：鸡兔共 12 只、脚 34 只 → 兔 5 只。要求讲清“每替换一只差 2 脚”。
2. **工程合作**：甲 6 天、乙 10 天 → 合作 3.75 天。不能把天数简单相加取平均。
3. **溶液**：200g、20% 的溶液加水 50g → 16%；先找 40g 不变的溶质。
4. **利润**：进价 80、标价 120，九折和八折单位利润分别 28、16；要明确差额基于同一标价。
5. **插空/补集**：5 个不同人排队，A、B 不相邻 → 72 种；注意相邻的 2 种内部顺序。
6. **独立重复**：成功概率 1/4，独立做 3 次至少成功一次 → 37/64；若改为“不放回”，应拒绝沿用该式。
7. **周期边界**：第 1、4、7 天发生，问第 10 天 → 发生；检验 `(N−1) mod 3`。
8. **相似立体**：边长变 2 倍，表面积变 4 倍、体积变 8 倍；不能混同平方与立方。
9. **无答案输入**：任一上述题移除参考答案，要求明确标记“独立求解”，不说“系统已判对”。
10. **条件缺损**：不告知鸡兔总只数只告知总脚数，要求说明不能确定唯一解；不得猜选项。

## 5. 标准输出示意

```text
答案：B（独立求解；原题若无答案则写明）
题型：工程问题 / 效率与时间
最快破口：同一工程量，赋最小公倍数使效率整数化。
考场步骤：总量设 30；甲效率 5，乙效率 3；合作 30÷8=3.75 天。
为什么稳：所求只有同一工作量，份数赋值不改变用时。
校验：3.75×(1/6+1/10)=1（完成一项工程）。
易错点：不能直接取 6 天和 10 天的平均值。
```

示例中的选项字母仅适用于实际题目包含对应选项时；若题目没有给选项，写数值结论即可。
