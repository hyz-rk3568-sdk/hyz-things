# 逻辑判断：形式推理专项和 S1–S4 目录

## 边界

知识库仍包含论证推理与形式推理；当前逻辑判断专项**只练形式推理独立题**，排除论证推理、原因解释、图推、定义、类比、日常结论、一拖五及共享材料题组。

## 小P S1–S4 分类

| 子目录 | 解题入口 | 方法卡与错题 |
|---|---|---|
| S1-直言命题 | 集合推理、所有与有的、三段论、画图 | `cards.md` / `错题/cards.md` |
| S2-联言选言假言命题 | 翻译、真假命题、两难推理；平行结构为现有补充卡 | `cards.md` / `错题/cards.md` |
| S3-组合排列 | 排序、位置、分组选人、优先级 | `cards.md` / `错题/cards.md` |
| S4-特殊题型 | 真假话、排身份、对应匹配 | `cards.md` / `错题/cards.md` |

四个目录统一置于 `flashcards/判断/形式推理/`，不再维护上一层混合卡片文件。

## 卡片合并与表述

以用户上传的《小P-27判断.md》S1–S4 为指导，使用「先实线后虚线」「前推后／后推前」「肯前必肯后、否后必否前」「鲁滨逊定理」「找题眼」「能推则推、推不动假设代入」「脚下踩着几个」「排掉 n−1 个即锁定」等术语。

- S2 将翻译与假言/选言互换合并成一张，留原个人卡 ID；独立的真假命题、两难推理、平行结构卡不合并。
- S3 将分组选人基础规则与选人优先级合并成一张，留原个人卡 ID；排序、位置各保留独立卡。
- 现有四张真实错题按可见题意与复盘内容归入 S1/S3/S4；S2 保留空错题文件。图片 `IMG_0150.png` 题干尚未核实，因原卡的「推不动就代入、证明为真就取反」对应 S3 假设代入/四问四带，暂归 S3，待核对后可调整。
- 现有个人方法不被外部总结悄悄替换；无法从原错题图片完整核实的细节不擅自补写。平行结构在此份小P材料中未有完整独立步骤，因此明确标注「现有补充」而非小P原话。

## 命题与检验

每卷 10 道四选一独立题，限时 10 分钟，不强制 S1–S4 配额。只从上述八个方法/错题文件选取已同步且有效的卡片；Codex 用卡片原有规则命原创题，自行检查条件完整、正确选项唯一、解析一致。

- 合并后的方法卡按新目录维护，仍保留当前活跃卡的 ID；不再保存重复来源卡 ID 注释。
