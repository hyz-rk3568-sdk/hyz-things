### S1 · 直言命题

**判据**：出现"所有/有的/某个"+ 判断真假、能推出。

**六种形式与区间**
| 形式 | 区间 | 关键 |
|---|---|---|
| 某个A是/不是B | 不论范围 | 二者矛盾 |
| 有的A是B | 0%＜x≤100% | 可到 100%，**不蕴含**「有的A不是B」 |
| 有的A不是B | 0%≤x＜100% | 不能推「有的B不是A」 |
| 所有A都是B | 100% | 可能全同 |
| 所有A都不是B | 0% | ＝所有A都是非B |

**图规则**：实线＝范围确定；「虚线……就是并不确定这个A的具体范围，它想去哪就去哪」。

**推导**：有的A是B ⇄ 有的B是A；所有A都是B → 所有不是B的都不是A；**所有A都是B ＝ 没有A不是B**。

**三段论四搭配**（每条都以"所有A都是B"作桥梁）：
1. **所有A都是B ＋ 所有B都是C → 所有A都是C**
2. **有的A是B ＋ 所有B都是C → 有的A是C**（＝有的C是A）
3. **有的A是C ＋ 所有A都是B → 有的B是C**（＝有的C是B）
4. **有的A不是C ＋ 所有A都是B → 有的B不是C**（也可说成"有的不是C的是B"）

**核心**：「**只有存在这个所有A都是B才能去推出确定性结论**」——"所有…都是…"是传导的桥；两个"有的"推不出确定结论。

**四种关系**（他的命名）：**矛盾**（无交集且覆盖全部→必一真一假）／**全覆盖**（覆盖全部但有交叉→至少一真）／**反对**（无交集但不覆盖→至少一假）／**包含**（小真则大真）。

**口诀**：「**所有跟有的换一下，是和不是换一下**」；「矛盾关系……像那种**一夫一妻制**」；「**所有能推特指，特指能推有的**」。

**SOP**
- 集合推导：2 句→三段论；3~4 句→画图；5~6 句→回三段论。画图**先实线后虚线**。三段论拿选项"尾巴"回题干找桥。
  > 注：他讲课时**两种说法都出现过**——一处说「条件少你就画图；条件多你就用三段论」，另一处说「这个题条件太少，只有两句话，用三段论会更快」。**实战按上面的分档走**：2 句用三段论最省，3~4 句画图能一次照顾四个选项。
- 真假话：**先找矛盾 → 全覆盖 → 包含 → 假设代入**；拿到新信息**回头再判**。
- 「并非」句**先翻译**。

**取舍**：「只有一真」只找矛盾、全覆盖、包含，**不找反对**（反对只保证至少一假）；「只有一假」找矛盾、反对、包含。

**高频坑**
- 「有的A是B」被脑补成「有的A不是B」（交集可以 100%）。
- 「有的A不是B」倒过来用（不能得「有的B不是A」）。
- 由「所有A都是B」推「有的B不是A」（可能全同）。
- **把反对当矛盾**（最致命）。
- 「特指」与「有的」范围搞反。
- 死抠"以上/以下"取等（「不要在意这个能不能等于」）。

### S2 · 联言选言假言命题

**标志词**
- 联言：「且」「而」、**逗号**、「但」。
- 相容选言：A或B＝「至少一个成立」；替代表述「至少提拔一人」。
- 不相容：「要么…要么…」。
- 前推后：「如果A那么B」「只要A就B」「一旦A则B」「所有A都是B」。
- 后推前：「只有A才B」「不A不B」「没有A就没有B」「除非A否则不B」。
- **必要性标志词清单**：「只有」「不…不…」「没有…就没有…」「除非」，以及「**关键、基础、核心、前提、必须、必不可少、不可或缺、本质要求**」。
- 顺承：「从而」「进而」——「能起到逻辑链的顺承作用」；没有它就只能并列。

**规则表**
| 类型 | 真假 | 推导 |
|---|---|---|
| 联言 A且B | **全真才真** | A且B真→A真、B真 |
| 相容选言 | 至少一真 | **否一推一**；肯一推不出 |
| 不相容 | 一真一假 | 知其一必推另一的反 |
| 假言 A→B | 只有「A且否B」为假 | **肯前必肯后、否后必否前**；否前/肯后推不出 |
| 鲁滨逊定理 | — | **A或B ＝ 否A→B**；**A→B ＝ 否A或B** |

**合成**：A→B、B→C ⇒ A→C；A且B→C ⇒ 否C→否A或否B；A→C、B→C ⇒ **A或B→C**；A→B、A→C ⇒ **A→B且C**。
**「加或扩大范围，加且缩小范围」**。

**矛盾写法**（四情况框架）
1. A且B 的矛盾＝**否A或否B**（「且换成或，组件分别取反」）。
2. A或B 的矛盾＝**否A且否B**。
3. **A→B 的矛盾＝A且否B**（最关键，"前真后假"）。
4. 要么A要么B 的矛盾＝（A且B）或（否A且否B）。这一条他课上没逐字给结论，**用到时自己按"四情况"推一遍**。
5. 「至多一个」＝否A或否B。

**SOP**
- 翻译推理：先翻译 → 题干长就先看选项 → 只用两条路（肯前/否后），出现肯后/否前**直接排除** → 多句串联 → 问"为假"先求矛盾。
- 真假命题（**按"几真几假"分两路，顺序不能混**）：
  - **「只有一真」**：先找矛盾 → **全覆盖** → 包含。（**不找反对**——反对只保证"至少一假"，给不出"真在哪"。他的原话：「如果题干只有一真，我就会更倾向于去找矛盾关系跟全覆盖关系跟包含关系，不去找反对关系。」）
  - **「只有一假」**：先找矛盾 → **反对** → 包含。（**不找全覆盖**——「全覆盖关系可能都是真，它不一定有假」。）

**取舍**：「先抓大放小」（"没有激发"与"很难激发"视为同义）；**因果句不能翻译**（「因果关系不代表充要关系」）；**不反对乱代入**（「没有这种章法」）。

**高频坑**：否前/肯后误当能推；把"否前恒真"当"整题恒真"；充分当必要；逗号/"但"当转折忽略；「没有A不B」与「不A不B」混同（方向相反）；「或」凭空加项就排除；只有一假却找全覆盖；**忘记先找矛盾**。

### S3 · 组合排列（一拖五）

**适用范围**：「行政执法卷、地市卷会有这个一拖五；副省级没有，会换成加强削弱。」
**本质**：「一拖五这种题目里面**更多的是排位置**。」

**整体策略**
- **按顺序做**：条件"大概读一下"，然后一题一题做，不跳题、不先攻第 5 题。
- **难度分布**：前 1~2 题送分；第 5 题常是计数型，「孤立看很难」，但可用前面写出的可能情况兑现。
- **三条总纲**：①「一拖五，**不要上来就放弃**」；②「有时候要结合一下这个前提的结论，看看能不能跟后面的产生关联」；③「**能推则推，推不下去了，你就去假设去代入**」。
- **关键限制**：「这个条件你只能在这个题目里面用，后面的三四五题、包括前面第一题……**你不能把它当个条件去用**。」可复用的只是前面写出的**可能情况**。

**核心方法**
| 方法 | 判据 | 怎么做 |
|---|---|---|
| **直言命题＝突破口（"车钥匙"）** | 有确定信息 | 「就像车的链条，给你一个钥匙，往里面一扣，整个车就转起来」 |
| **高频对象（"题眼"）** | 全是假言、无确定信息 | 「多去观察频率高的对象」，串成链 |
| **递推（串糖葫芦）** | A→B 与 B→C | 后件接前件；遇否后先转正向 |
| **两难推理** | 前件全覆盖/矛盾 | A→B 且 否A→B ⇒ **B 恒真** |
| **优先级推理（选人模型）** | N 选 M（N−M 个不被选） | 「选A就选B ⇒ **B 的优先级高于 A**」；"脚下踩着几个"≥N−M 则必选 |
| **优先级边界（3、5 可用，4、6 不用）** | — | A或B→C 可用；**A且B→C 不可用** |
| **四问四带** | — | 「可能为真、必然为假的**正面带**；必然为真、可能为假的**反面带**」 |
| **剩余价值** | 命题被否前/肯后 | 「没有剩余价值」→ 划掉 |
| **相似思维（3+2）** | 总数不对称 | 「不能在同一列的你就给它放一行」 |
| **相斥思维** | 「均不相同」 | 直接占一行，其余自动归位 |
| **多限制条件优先** | 隔三个/隔两个并存 | 「步子跨得越大，可能的情况数就越少」 |
| **等价/同构（偷鸡）** | 两人条件完全一致 | 同构选项一起排除 |

**SOP**：概览材料 → 抓确定信息 → 落表落位 → 优先推 → **销账** → 卡住就假设/代入（**一种可能只能排除，不能证明恒真**）→ 按问法带 → 跨题只复用可能情况 → 兜底用同构。

**取舍**：「没有无缘无故的第一小问」；第 5 题不硬推；无中生有直接排除；「胆子大」可"直接否前"省时但"不能打包票"。

**高频坑**：把"不能推出"当"必然为假"（**这是出题人都搞混的地方**）；跨题借用补充条件；把"一种可能"当"恒为真"；反复回看已榨干的条件；优先级乱套 4、6 号命题；忽略数量约束；捆绑对象算人数算漏（「看似三个，其实五个」）。

### S4 · 特殊题型（排身份/数独/真假话/半真半假/大大则大）

**这五块的地位**：「形式推理里考的频率相对比较高的模型题。」底层二分：排身份、数独＝**排除性**；真假话、半真半假＝**假设性**；大大则大＝**口诀型**。

**① 排身份**
- 条件用**排除型语句**给：「不是」（直排）／「比他高一点」（能比较即不同一）／「一起打篮球」（属性不一致即不同一）。
- 步骤：找**涉及条件最多**的人当破题口 → 尽量排，**n 对 n 排掉 n−1 个即锁定** → 双向皆可 → **锁定后代回其他条件** → 假言条件留到最后否后推否前。
- 独门：一维连线太乱就**升维画图**。

**② 数独**
- 四种思路：**选项排除／十字交叉（横竖牵扯最多的点）／多管齐下（"推土机"）／转弯相同（粗线框专用）**。
- 转弯相同原理＝**补集一致**；进阶＝两个空格**共享排除信息**。
- 视线规则：「**横过来推就竖过来看，竖过来推就横过来看**」。
- 抓出现最多的元素（「他把发展搞这么多，就是告诉你你要拿它去做」）。

**③ 真假话**
- 找**有特殊设定的对象**，看哪句话聊到他 → 假设代入找矛盾（「骗子可不可能说自己是骗子」）→ 整句取反并**连带** → 多句互指用「打保票」→ 追求恒真。
- 潜规则：**话题人默认≠说话人**（「司机说丙不是诈骗犯」→ 丙不是司机），「做不出来再放宽」。

**④ 半真半假**
- **交叉排除**：由「甲是班长，乙是学习委员」对一半，得「**甲一定不能是学习委员，乙一定不能是班长**」。
- 前提：一一对应、不重叠；选项是全排列时最快。
- 不适用→回归假设代入；正面无矛盾只叫"可能为真"，靠**选项间反对关系**收口。
- **他明确否定"冠军模型"**（最少/最多即真）：「它没有底层逻辑。」

**⑤ 大大则大**
- 结论：A>B、C>D ⇒ **A且C > B且D**，且「**ABCD 都得是矛盾属性**」。
- 铁律：「**你只能推这一个结论，这个结论是唯一的。**」
- 反向题：已知交集优于交集，要补**整体劣势**那个条件。

**高频坑**：两句话≠两个条件（有"且"就是联言）；假言不能当排除句；数独填到已有该字的行列；无粗线框却用转弯相同；数独硬推全；整句假≠每句都假；交叉排除用在非重叠关系上；把"可能为真"当"可以推出"。
