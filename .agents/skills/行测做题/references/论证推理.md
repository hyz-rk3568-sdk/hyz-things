# 论证推理：一套通用推理操作系统

## 来源和使用优先级

主要来源：`hyz-things/flashcards/判断/论证推理/card.md`；配图 `flashcards/images/论证推理-横向对比.png` 和 `IMG_0146.png`（用户已上传可见图片）。尊重用户的术语、做题顺序及实际题目原意。图片是分类方法的示范，不要误当成所有题目只能用图片中有限的举例。

> **总纲：论证推理就是判断“论据 → 论点”是否可推。** 先把“据”和“点”写清，再检验桥梁，最后依据提问方式挑最切题、力度最强的选项。

把三个维度分开：
- **推理结构**：直接推得出？中间缺桥？事实与结论是否错位？
- **证据组织**：普通事实、横向对照（不同对象）、纵向对照（同一对象前后）、仅观察到相关性的由果推因（常伴随隐含横向比较）。这几种可以重叠，不是互斥的“三级题型”。
- **问题要求**：削弱 / 支持 / 前提假设。问题不同，对同一选项的评价标准不同。

## 核心操作（每题都用，避免机械分点套模板）

**第一问：点是什么，据是什么？** 结论说的是发生了什么、谁造成的、为什么造成的、还是从局部推广到全体？论据实际观察/比较/证明了哪一层？保持对象、时间、数量、指标、范围一致。

**第二问：据如何推点？** 明写缺的那一步：从相关到因果、从分数到能力、从某种游戏到所有游戏、从某两组差异到某具体机制，等等。若论据已直接支持结论，也要检查统计口径、基准与混杂变量。

**第三问：选项动哪里？** 它否定了已给事实、指出原因不成立、补/断了桥、证明了别的原因、还是直接冲突于论点？不能只因出现“其他因素”“可能”就判为他因；要说明它怎样改变论点可推性。

**第四问：根据问法验力度。** 支持题看是否提升结论可信度；前提题看否定后原推理是否断裂；削弱题看对原论证的直接破坏程度。选项两两比较，防止正确但无关或弱相关。

## 对照试验：一张比较表 + 三道检查

先画最小比较框架，无论显性实验还是隐含对照：

| | 实验组/处理组（类比） | 对照组/比较基准（类比） |
|---|---|---|
| 研究因素/处理 | A 的状态 | A 的对比状态 |
| 结果指标 | B 的状态 | B 的对比状态 |
| 可能改变结果的其他条件 | C、D 是否不同 | C、D 是否不同 |

- **横向**：不同对象间比较；**纵向**：同一对象的前后比较，把表两列改为“实施前/实施后”。纵向仍要核查同期变化。
- 对照组由题干的**实际基准**决定；非实验组不必然等于对照组，两组不要求覆盖全部人群。例如“脂肪过少 vs 正常”不可擅自改成“过少 vs 一切非过少”，脂肪过多可以是第三组。
- 观察到的分组不等于真正随机分配的实验。题目仅有观察数据时，用“实验组/对照组（类比）”并注明隐含比较，不虚构随机分组或前测。

### 图片原例：玩游戏是否提高学习能力

研究者把30名原本不玩网络游戏的大学生分两组，一组玩一个月、每天一小时，另一组不玩；实验后发现玩游戏组**测试分数**高一些，于是宣布“玩游戏能提高**学习能力**”。图片给了三条可以迁移的分析路径：

**1. 控制变量 / 起点是否可比。**
- 削弱：实验前，游戏组的测试平均分就比对照组高不少。**原有水平差异**可以解释最终分数差异；不能直接归功于玩游戏。
- 支持：实验前两组的测试平均分几乎一致。排除明显的初始水平差异（但不意味着排除全部干扰因素）。

**2. 解释因果联系 / 为什么能造成结果。**
- 例如：游戏刺激大脑部分区域、促进神经元连接形成和强化，进而可能提升学习能力。该信息是从游戏到能力的**机制解释/补桥**，必须审查机制是否真的连接本题的 A 与 B，不能只因专业名词多就当成强支持。

**3. 实验结果能不能推出论点 / 推广是否过界。**
- “分数更高”不自动等于“学习能力更强”：若考试分数的个别差异不能代表能力差异，属于**指标到结论的论证断裂**。
- “网络游戏实验”不自动推出“所有游戏”：若游戏内社交协作才是关键，而单机游戏不具备它，则**限定因果作用范围、削弱泛化**，不能直接从网络游戏推广到全部游戏。
- 相反，若“考试分数是体现学习能力的关键指标”，就补强了从**测量结果到所谈能力**的桥；这不等于直接证明玩游戏的因果效应。

### 怎样准确区分否原因、他因、否论证、否论点

先从**选项实际反对的命题**而非词面归类；同一个选项可能同时跨类别。

- **否原因**：反驳作者指定的致因 A 或其起作用的条件——例如 A 并未发生、没有形成所声称的差异、在所述情境中并不能产生声称的作用。务必交代是“原因事实不存在”还是“原因没有致效作用”；这两者不完全相同。
- **他因**：存在另一个因素 C **足以解释题干所观察的结果/组间差异**。可从实验组特殊之处、对照组特殊之处或共同原因切入；“有其他差异”如果无法影响 B，不构成有效他因。图中的“实验前游戏组本就分数高”也可描述为基线混杂/他因，不能硬贴单一标签。
- **否论证（拆桥）**：即使承认论据真实，也**推不出题目说的结论**，如分数不能代表学习能力、样本群体不代表全体、从网络游戏推不出所有游戏、两组统计口径不可比。这是**论据与论点之间的错位**，不等于推翻试验观察值。
- **否论点**：直接与结论冲突，如可靠证据表明玩游戏实际上没有提升学习能力。若论点为 A→B，证据揭示 B→A 则属于典型因果倒置；但仅有 B→A 的可能性不必然证明 A→B 绝不同时存在，比较力度时注意陈述强弱。

**特别防混淆**：试验只得出“实验组分数较高”，作者却说“游戏提高学习能力”。分数差异是 B（观测结果），学习能力是要推断的另一个层面；“游戏导致”又是因果层面。先拆成“比较 → 测量代表性 → 因果归因 → 推广范围”，看选项切断哪一步。**不能把“结果不足以证明原因”一概贴成“否原因”；很多时候准确标签是拆桥/否论证。**

## 由果推因：在常规分析里显式还原“隐含对照”

典型结构：观察到 B 或 A 与 B 同现 / A 组 B 更多（据），便断言“A 引起 B”（点）。隐含比较可能是 A 高/低、A 有/无、出现 B/未出现 B 等；必须先按**题干原本比较方向**重建，不要凭空创造样本或数值。

每道由果推因题的解析必须写出：

> 实验组（类比）＝谁，研究因素 A＝什么，结果 B＝什么；对照组（类比）＝谁、与前者何处不同；题干已经证实的差异是什么；作者由此归因 A→B，中间缺哪个保证；是否存在 B→A、C→B 或 C→A 且 C→B。

若题干没有显性分组，说“**隐含比较假设**”；若连隐含横向组都不足以确定，直说“比较基准未知，不能可靠指定对照组”，再描述候选比较基准，**不能编造实验**。纵向数据先还原前后，再考虑是否存在有效横向比较。

- **削弱优先考虑的路径**（保留用户 Flashcard 速判）：否论点（含因果倒置）→ 拆桥 → 论据/他因 → 反例。此顺序是提醒检查的路径，最终仍比较选项与论点的实际关系；强他因可能胜过弱而空泛的否论点表述。
- **加强**：排除真正影响 B 的组间差异、证明 A 先于 B、提供 A→B 的机制、用恰当证据验证干预效应，并注意结果指标是否与论点相同。
- **三种关系分别问**：A→B（原论点）、B→A（因果倒置）、C→B / C→A 且 C→B（他因或共同原因）。不能因为“有其他原因”就默认原因为假；要判断它是否解释了题干的现象且削弱了原归因。

## 加强题：先看提问方式，再决定是否找必要条件

这来自第二张图片，不能混成一条笼统“补桥”。

**支持类（支持/加强/最能支持）**：要找能提升“据→点”可推性的内容。
- **有断点**：优先找能连接断点的**搭桥**，并比较桥的直接性与力度。
- **无明显断点，且论据不直接推出结论**：找能提供连接说明的**搭桥**。
- **已有直接推断**：找**补充论据**，如独立数据、机制、控制变量或重复验证。
- 对照试验尤其看初始条件接近、排除混杂、解释因果机制、测试指标是否代表论点对象、结论是否过度外推。

**前提/假设类（必需前提、依赖哪项假设）**：找**必要的桥或条件**，不是找最会增加可信度的证据。
- **有断点**：重点考察必要的搭桥条件。
- **没有明显断点**：重点寻找论证暗含的**必要条件**；不要把“能加强”直接当“必需”。
- **否定代入**：否定备选项，再看原来的“据→点”路径是否失去成立基础；判断的是这条**论证能否成立**，不是现实中结论是否一定为假。
- 支持题允许“有它更可信，但没它未必不行”；前提题要求“没有它，这条推理不成立”。

## 作答模板（按信息密度自适应，不强制长篇套表）

普通题：**答案 → 论据/论点 → 关键推理桥梁 → 正确项怎么作用于它 → 主要干扰项为什么不如它。**

涉及对照：额外给**实验组/对照组（或前/后）、研究因素、结果、其他变量**；按“起点可比 → 因果解释 → 结果能否推出/推广到结论”的框架定位选项。若有多重变量不宜只把它们叫“没控制变量”，需指明具体推理断层。

涉及由果推因：**必须解释隐含对照试验**，指出哪些是观察事实、哪些是作者归因、哪些是待证假设；检查他因、倒因果及比较基准。不为简洁省略这一项。

涉及前提：**必须展示否定代入**和为何论证会断；涉及支持：**必须说清是搭桥还是补充，以及为何更直接**。

复盘时尊重用户现有速判方法，只纠正确实的错误。若用户说“转成错题”或“转成 flashcard”，严格使用既定 Markdown 源码格式，不自行改写其原有方法。

## 防止把示例当规则

- “实验前分数接近”仅是**支持基线可比**的一个例子，不是支持题的统一答案。
- “考试分数能体现学习能力”是**指标有效性搭桥**，不是直接证明因果。
- “单机游戏不具备社交因素”是否削弱要看**论点是否推广到所有游戏**，不要忽略量词和范围。
- “他因”“否原因”“拆桥”往往可从不同层面描述同一材料；不必强求唯一命名，优先用一句准确解释指出**攻击点**。
- 不得声称隐含观察性比较就是随机对照实验；不得假造前测、控制条件、因果效应。
