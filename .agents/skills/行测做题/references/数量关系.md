# 数量关系

首版仅以 `flashcards/数量/` 下11组有效方法卡或已有真实错题卡为命题源，不包含几何、特殊题型、数字推理。按照题目辨认考点，方法可跨目录组合。优先阅读 [小P数量方法](小P-数量关系-解题方法.md)；不要把来源课程方法称为 hyz 本人独创。

每卷10道原创独立四选一题，15分钟。每个目标卡片生成一道，正确选项须唯一，数值、单位、解析和目标式一致。Codex负责语义与数学自检，服务端负责结构与身份校验，未交卷不得泄露正确选项、答案或卡片背面。VCNT与逻辑判断、资料分析独立。

卡片布局：经济利润、工程效率、行程/相对运动、行程/综合应用、溶液、最值、排列组合/基础、排列组合/插空与同素分堆、排列组合/特殊套路、概率、周期。方程与和差倍比是通用基础，不单独形成首版题型。
