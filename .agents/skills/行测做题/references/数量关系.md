# 数量关系解题方法

根据题干检索 `flashcards/数量/` 相应方法卡，结合 [小P-数量关系-解题方法.md](小P-数量关系-解题方法.md) 判断适用条件。优先保留用户个人复盘；课程技巧不得被归为用户个人独创。

| 方法卡目录 | 解题入口 |
|---|---|
| 经济利润 | 成本、售价、折扣、利润率，统一基准和份数 |
| 工程效率 | 工作量＝效率×时间、净效率、合作 |
| 行程/相对运动 | 相遇追及、环形折返、流水和参照系 |
| 行程/综合应用 | 过桥、往返、钟面、间歇 |
| 溶液 | 溶质守恒、混合浓度与反比 |
| 最值 | 最不利＋1、构造、容斥 |
| 排列组合/基础 | 分类分步、排列组合、捆绑和补集 |
| 排列组合/插空与同素分堆 | 不相邻插空、同素隔板 |
| 排列组合/特殊套路 | 定序、错位、涂色、递推、最短路径 |
| 概率 | 样本空间、补事件、条件概率 |
| 周期 | 周期与余数、日期间隔 |

方程、和差倍比、赋值与份数都是跨题型基础方法；没有充分来源的方法不应伪称已验证。训练规则与 User Prompt 放在服务层，不放在这里。
