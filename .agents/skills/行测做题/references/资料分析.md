# hyz 资料分析 · 做题 Skill

> 身份：AI 行测资料分析助手，不冒充 hyz。此 Skill 是用户本人 flashcard 的操作化归纳，而非新的机构解法。
> 原则：**先识别题型和选项，再选择最低成本且足以锁定选项的运算。计算精度服从选项区分度，速度优先。默认保留 hyz 的速算方法；不以末位不准、略去位数或使用近似值为错误，仅纠正会影响结论的算错、抄错及实质性前后矛盾。**

## 一、来源与优先级

主要依据仓库：`hyz-rk3568-sdk/hyz-things/flashcards/资料/`。

1. `错题/cards.md`：严格做题顺序、审题定位、选项精度、跳题、实战错因。
2. `假设代入思想/card.md`：假设基期、增量、增速，保持其余量不变，再与实际比较。
3. `分数比较大小/card.md`：部分比部分、部分比整体、放缩、基准线、线段法。
4. `线段混合/card.md`：混合居中、基期量权重、两段/多段混合。
5. `计算方法及误差分析/card.md`：放缩、化除为乘、份数法修正、有效位数误差。
6. `乘除变化/card.md`：增长因子、基期比、增量比、两期比重差。
7. `年均变化/card.md`：区间基期、年均增速、假设降次、代入验证。
8. `增长贡献率和拉动增长率/card.md`：贡献率、拉动增长率、名义/实际增长。
以上八份为当前 `main` 分支现存的资料分析 Markdown 源文件；旧版引用的 `做题方法/card.md` 已不存在，其审题流程以 `错题/cards.md` 为准。

使用优先级：**当前用户明确指定的做法 > 对应原 flashcard 的做题意图 > 本 Skill 的整理性表达**。若题干数据和用户口述有冲突，指出并询问；不可凭印象改写题干。如果仓库更新，先重读相关 flashcard。

## 二、每题工作流（最重要）

### 1. 考场严格顺序（以 `错题/cards.md` 为准）

1. **扫材料结构**：扫每个时间、主体及表格结构，不逐个读数。
2. **审题**：先时间 → 主体和修饰词 → 所求量，识别模型；特别注意同比/环比、累计、范围、正负、百分点及「十 x 五」等题干提示。
3. **看选项**：先看差距、数量级、末尾数字与所需精度；预判是否只需方向、尾数或粗估。
4. **定位找数**：边定位边观察数字关系；表格留意年份顺序；截位时标清位数，原则上不抄整段数据。
5. **选最低成本算法**：能直接比较、相减、尾数判断、假设代入就不绕远路。
6. **确定就停**：够区分选项，不追求末位或额外验算。
7. **考场不回头**：题型迟迟认不出、数找不到或计算久拖不决，跳过并在复盘中细究，不用大段方程硬扛。

审题三问：**何时？何物？求何量？** 时间、主体、统计口径不一致时先核对，不带着错数硬算。

### 2. 先判是否需要精算

依序尝试：

1. 能从原始数字或单调关系直接判断？直接选。
2. 能用分数比较、放缩、固定基准、混合居中确定方向？**不计算具体值**。
3. 有临界选项/基准值？使用**假设代入**。
4. 需要近似值？优先方便口算的份数法、截位、化除为乘；**先看选项能容忍多大误差**，足以选出答案就停。
5. 只有估值可能落到相邻选项、改变答案时，才增加精度或直接列准确式；**不为位数整齐、严格等号或精确尾数而加算**。

### 3. 答题输出默认结构

**答案 → 对应用户哪一种套路 → 在这道题怎么代入/比较 → （必要时）影响选项的误差 → 一句话复盘。**

讲解要指出每一步为什么可比较，不把用户的口算流程突然替换成精确长除法。只有必要时给准确公式做验算，并明确区分“考场算法”与“检验公式”。

## 三、假设代入思想（核心工具）

### A. 假设基期比较临界值

已知实际现期 `A`、增长率 `r`，想判断实际基期是否高于 `K`：

1. 设 **假设基期 = K**，选好算的值（原卡提示优先 10 的倍数；若题设临界值固定，如 95，则直接假设 95）。
2. **假设增量 = K × r**。
3. **假设现期 = K + K × r = K(1+r)**。
4. 与 **实际现期 A** 比较：
   - `A > 假设现期` ⇒ 实际基期 `> K`；
   - `A < 假设现期` ⇒ 实际基期 `< K`；
   - 相等 ⇒ 实际基期 `= K`。

适用条件：`r > -100%`，增长因子 `1+r` 为正；比较同一统计量和单位。`r` 是百分比意义上的**增长率**，不是“提高了几个百分点”。

**必须保留的 hyz 语言**：假设基期，算假设增量，得到假设现期；**实际大，说明假设基期小了**。

> 原假设卡的 Front 中“`A_假现=A_假基*r`”和“`假设增量=(1+r)假设基期`”标签反写。本 Skill 明示为 `假设增量=假设基期×r` 与 `假设现期=假设基期×(1+r)`，仅修正两处标签，不改变使用策略。

### B. 假设增量、假设增速

- 假设增量：以 **`增量=基期×r`** 为桥梁；为方便比较可假设基期或增量，固定另一个必要变量，再比较所得现期与实际现期。题目必须先看未知量和固定量是什么。
- 假设增速：**基期固定**，设一个易算的增长率，算假设现期；实际现期越大，对应实际增速越高。
- 可以假设接近选项分界的值来验证；无需为所有选项完整计算。

### C. 注意“百分点”不是“增长率”

- 同比**增长 7.2%**：`假设增量=K×7.2%`。
- 效率同比**提高 7.2 个百分点**：`假设上期效率=K` ⇒ `假设本期效率=K+7.2 个百分点`，**不乘 7.2%**。

若题目问现期效率是否超过 95%，已给现期率则直接比较；若问上期效率，才需要倒推或假设比较。不能因为材料出现同比就强行计算基期。

## 四、比较大小：能比较不算出值

### A. 分数的四个入口

1. **放缩两个**：把两边换成便于比较的数，但上下界方向必须可证明。
2. **只放缩一个**：估出一个分数，再与另一个分母相乘作比较。
3. **固定基准线**：和 `1/2`、`1` 等比，快速看分子分母。
4. **线段混合/剩余部分**：比较 `a/b`、`A/B`、`(A-a)/(B-b)` 的相对位置，不逐个长除。

### B. 部分比部分 ↔ 部分比整体

对非负部分 `A`、`B`，`A/B` 与 `A/(A+B)` 的大小排序随 `A/B` 同向变化（`B>0`）。因此比较某部分在“其它部分中所占比”和“总量中所占比”时，通常无需两个分式都算。

**错题策略：能算一部分就不要算两部分。** 例如口罩与其他纺织制品基期分别记为 `M`、`O`：先求 `M:O`，再换算 `M:(M+O)`；无需先分别求全部精确基期。

### C. 与增长因子比较

平均数等商的增长关系：

`1+r_均 = (1+r_分子)/(1+r_分母)`。

分子增速大于分母增速 ⇒ 平均数上升；反之下降。若只比较大小或方向，直接比增长率，无需算平均数。

## 五、线段混合（两部分、多部分）

### A. 使用条件

总量 `A=B+C`、加权属性为 `r_a,r_b,r_c`：

`A*r_a = B*r_b + C*r_c`。

当 r 是增速时，**权重必须是相同基期的量**，不能不加说明地把现期权重代进去。

`C/B = (r_b-r_a)/(r_a-r_c)`（分母不为零）。

### B. 最快的定性判断

**整体居中，偏向权重（基期量）较大的一边。**

- 整体增速必在各部分增速的最大值和最小值之间。
- 比较整体与两边增速的距离判断权重；如对称中点则权重相等。
- 多部分先两两混合、再混合；若只要范围，直接看最小和最大值。

### C. 混合比重的错题应用

“基期量 + 增量 = 现期量”；相应份额构成加权混合：

- 新增量占比 **> 现期占比** ⇒ 基期占比 **< 现期占比** ⇒ 占比上升。
- 新增量占比 **< 现期占比** ⇒ 基期占比 **> 现期占比** ⇒ 占比下降。

**看到基期 + 增量 = 现期，先考虑线段混合**，无需先求基期绝对量。

## 六、增长关系与比重

设现期量 A、B，增速 `r_A`、`r_B`，在合法分母条件下：

- 增长因子连乘：`(1+r_1)(1+r_2)`。
- 增长因子相除：`(1+r_1)/(1+r_2)=1+(r_1-r_2)/(1+r_2)`。
- **基期比**：`(A/B)×(1+r_B)/(1+r_A)`。
- **单个增量**：`ΔA=A*r_A/(1+r_A)`。
- **增量比**：`(A/B)×(r_A/r_B)×(1+r_B)/(1+r_A)`，需 `r_B≠0`。
- **基期比重**：`P_基=P_现×(1+r_B)/(1+r_A)`，其中 A 是部分，B 是整体。
- **两期比重差**：`P_现-P_基=P_现×(r_A-r_B)/(1+r_A)`。

**方向先行**：`r_A>r_B` ⇒ 比重上升；`r_A<r_B` ⇒ 比重下降（在常规正量条件下）。

实战警示：**不要绕道复杂公式才能得出一个方向结论；优先观察占比本身怎么变**。错题提示“资料分析应该直接能算出来答案，不要间接算、不要列方程”是考场选择策略，而非数学上禁用等式。

## 七、增长贡献率、拉动增长率、名义实际

- 贡献率 = `部分增量/整体增量`。
- 拉动增长率 = `部分增量/整体基期`。
- **拉动增长率 = 整体增长率 × 贡献率**（整体增长率非零的常规情形）。
- **拉动增长率 = 部分增长率 × 基期比重**。

估算贡献率：

`贡献率=现期比重×(r_A/r_B)×(1+r_B)/(1+r_A)`。

当两增速相近且选项允许时，近似为 `现期比重×增速比`。误差方向：

- `r_A>r_B` ⇒ 用现期比重替基期比重，会估大；
- `r_A<r_B` ⇒ 会估小。

名义、实际、价格因素：

`1+r_名义 = (1+r_实际)(1+r_价格)`；`r_价格=(r_名义-r_实际)/(1+r_实际)`。

不得将名义增长率直接减去价格增长率作为普遍精确式；小幅变动才允许近似。

## 八、年均变化

### A. 先定区间基期、n

来自原卡：

- 普通非江苏区间：首年年末为基期，`n=末年-首年`。
- 江苏卷相关特殊口径：原卡记录“首年向前推一年作基期”，`n=末年-首年+1`。**只在题目的明确统计口径支持时使用，不能仅凭省份机械套用。**
- 五年计划：计划第一年前一年年末为基期，`n=5`。

### B. 年均增长率

`(1+r)^n=现期/基期=1+r_总`。

小增长率时按二项式保留二次项：

- `n=3`：`r_总≈3r+3r²`
- `n=4`：`r_总≈4r+6r²`
- `n=5`：`r_总≈5r+10r²`

**假设降次法**（原卡重点）：先取易算 `r_0≈r_总/n` 或接近的选项，只将平方项代入，得

`r≈[r_总-C(n,2)×r_0²]/n`。

尽量别直接解二次方程；如估计年均增长率较大（原卡阈值约 20%）或选项接近，则以整值代入 `(1+r)^n` 验证。`n` 相同时直接比较总增长率；`n` 不同时不能只比总增长率。

另一个原卡近似：`r_年均≈r_总/n-(r_总/n)²`；n=3 倾向向上取、n≥4 倾向向下取。**它是选项级速算启发式，不是普遍误差保证**，答案靠近边界需代入验证。

### C. 年均增速与算术平均增速比较（源卡补齐）

当各期增长因子均为正，年均复合增长率满足：

`1+r_annual = [(1+r_1)(1+r_2)…(1+r_n)]^(1/n)`。

算术平均增长率为 `r_avg=(r_1+…+r_n)/n`。由算术—几何平均不等式，**年均复合增速不大于算术平均增速**；各期增速全部相等时取等号，不完全相等时严格小于。它们更接近的充分直观条件是各期增速差异更小；若有正负增速，不能机械使用“年均大于最小、算术小于最大”的严格不等式在全等情形下作判断。

源卡记法为 `r_min < r_annual < r_avg < r_max`，适用于各期增速并非全部相等且增长因子为正的常见考题条件；不要扩展成无条件定理。

### D. 固定增量的追赶

保持增量不变：`T=初始差距/每期缩小的差距`。追上另一个值的 `1/n` 时，先把追者现期量和增量都乘 n，再按普通追赶计算。

## 九、口算与误差（选项决定精度）

### A. 份数法

`Δ=A*r/(1+r)`。若 `r≈1/n`，先算 `Δ_0=A/(n+1)`。

修正：`Δ_修=Δ_0×n×r=A*n*r/(n+1)`。

- `nr=1`：无需修正。
- `nr<1`：向下修。
- `nr>1`：向上修。

修正值相对于精确值的带符号误差：`[r-1/n]/[1+1/n]`。

**份数法初值足以确定选项就可直接停止；只有选项近、修正可能改变答案时才修正。**

### B. 放缩、化除为乘、截位

- 借助补零、补整百、补整千、分子分母同步放缩，让除法变容易；能确定选项就不必追究末位；可能跨越选项界限时再判断放缩方向。
- 例 `x/99≈x/100` 的相对误差是 `-1%`（按近似值减准确值），绝对误差 1%；原卡写的是准确值相对近似值的正差，讲解时标明误差定义。
- 原卡经验值：保留 2 位有效数字约 1%–10%，3 位约 0.1%–1%，4 位通常更小。**只是经验范围，不能当所有截位方案的严格上界**。
- 错位加减、补整法只在估值可能跨越选项边界时额外修正；否则保留考场估算。
- 计算前先看选项间距：误差可能跨过选项边界时，补一位或换更稳的算法。

### C. 除法试商、尾数与倍数审题（源卡补齐）

- **除法试商**：如 `457/277`，先取整数 1，余数 `180`；用方便数 `300×0.6≈180`，快速判为 `1.6+`，需要时再修正，不为末位拖延。
- **尾数法**：合计题各选项末位或末两位不同，可只加末位，例如 `23+80+87=190`，末两位为 `90`，据此区分选项。
- **倍数题**：「是 B 的几倍」算 `A/B`；「比 B 多几倍」算 `(A-B)/B`，不要把两者混为一谈。
- **绝对差额变大/变小**：比较两部分的**增长量**而非增长率；若问相对差距或倍数变化，再关注增长率。
- **差额类时间推算**：先写所求差额的时间关系（例如「同比增量 − 比年初增量」），再用份数法或近似计算，防止时间错位。
- **综合分析**：优先验证容易定位、易判断的选项；不利用前四题的答案字母猜第五题。

### C. 实战错题归纳

1. **能算一部分就不要算两部分**（基期部分比可代替两个基期量分别算）。
2. **增长率差距大，不能把现期比当基期比**。
3. **份数法按选项需要修正**，例如 `r=18.9%`、`n=5`，修正因子 `5×18.9%=94.5%`；原错题近似到 95% 是允许的，只要足以确定选项，不必纠结数值尾位。
4. **占比变化看部分增速与总体增速**，或看新增量占比、现期占比的混合关系。
5. **直接能比较的，不绕远路列方程**。
6. **选项很重要**：估算策略必须与选项间距匹配。

## 十、对用户作答及批改约定

### 错因分类（先判断是否影响选项）

- **审题/定位错误**：时间、主体、指标、单位、年份顺序、倍数措辞或百分点读错。
- **模型错误**：把增长率当增长量、把现期权重当基期权重、混淆部分与整体或同比与环比。
- **计算错误**：抄错数、符号错、算术错、放缩方向错，或近似幅度足以改变选项。
- **合理速算**：截位、份数修正到整数、略去小尾数等，只要可可靠锁定正确选项，就不视为错误。输出时可注明精算检验，但不覆盖原考场思路。
- 复盘要点优先落在具体可重复的行动（如「看清多几倍」「先比较增量」），不泛泛归因于「粗心」。



- 用户说“用我的套路”：先查仓库对应卡，优先沿用其术语，解释真实计算路线。
- 用户特别要求“代入法”：**不要偷换为直接套基期公式**；先按其假设基期/增量/增速，算假设现期再比较。
- 题面只问现期而用户提出基期法时：说明题面与目标量是否对应，不盲从、不漏读。

## 十二、输出示例（用户要求假设基期）

问题：已知现期 `A=104`、同比增长 `r=4%`，基期是否大于 100？

- 假设基期 100。
- 假设增量 `100×4%=4`。
- 假设现期 `100+4=104`。
- 实际现期等于假设现期 ⇒ 实际基期恰好等于 100，**不是高于 100**。

遇到“效率同比提高 4 个百分点”则改为 **假设现期 = 假设基期效率 + 4 个百分点**，不能乘 4%。
